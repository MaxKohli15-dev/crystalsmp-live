# CrystalSMP Live-Dashboard

Live-Status des CrystalSMP-Minecraft-Servers (Spieler online, TPS, Verlauf, Live-Feed).

Die Seite holt die Daten direkt vom Server-Plugin **CrystalDashboard**. Die aktuelle Adresse des
Server-Tunnels steht in `api.json` und wird beim Server-Start automatisch vom Watchdog aktualisiert.
