Regeln
  1. Keine Hacks, Cheat-Clients oder Makros. Das Anticheat erkennt sie: Kick, Kick, dann Bann.
  2. Kein Bug-Using und keine Dupes. Gefundene Bugs bitte melden.
  3. Respektvoller Umgang im Chat – keine Beleidigungen, kein Spam, keine Werbung.
  4. Kein Griefen und kein Stehlen auf fremden Grundstücken.
  5. Kein Lag-Machen mit absichtlich riesigen Farmen oder Maschinen.
  6. Die Entscheidungen des Teams gelten. Spieler melden: /report
Fragen
Wann startet der Server offiziell?

Am 3. November 2026. Bis dahin kannst du schon reinschauen – der Countdown oben zeigt, wie lange es noch dauert.

Brauche ich Mods?

Nein. Auf Java lädt das Resourcepack beim Joinen automatisch, auf Bedrock brauchst du gar nichts.

Kann ich mit Bedrock und Java zusammen spielen?

Ja. Alle spielen auf derselben Welt, egal ob PC, Handy oder Tablet.

Welche Version brauche ich?

Java: 1.21.4 oder neuer. Bedrock: die aktuelle Version aus dem App Store.

Kostet ein Rang echtes Geld?

Nein. Alle Ränge kaufst du mit Ingame-Geld über /rangshop.

Geht es auf Xbox, PlayStation oder Switch?

Konsolen lassen eigene Server nur über Umwege zu, zum Beispiel mit der App „BedrockTogether“ auf dem Handy.

Sei am 3.11. dabei!
